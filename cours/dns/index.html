DNS

1. À quoi sert le DNS ?

Le DNS (Domain Name System) permet à un ordinateur de trouver l'adresse IP associée à un nom.

Grâce au DNS, nous utilisons des noms faciles à retenir plutôt que des adresses IP.

Exemple sur Internet :

Le serveur DNS associe le nom www.athenyx.net à l'adresse IPv4 192.0.2.10.

Exemple dans une entreprise :

Le serveur DNS peut associer le nom srv-fichiers.entreprise.local à l'adresse IPv4 192.168.1.10.

Quand ton ordinateur veut contacter un serveur, il peut demander son adresse IP au serveur DNS.

Le serveur DNS lui répond. Ton ordinateur peut alors contacter le serveur recherché.

3. Structure d'un nom de domaine

Exemple : serveur1.infra.athenyx.net

Hôte : serveur1
Sous-domaine : infra
Domaine : athenyx
Extension (TLD) : net

Les noms DNS sont organisés de façon hiérarchique, à partir de la racine et du domaine de premier niveau.

4. Les enregistrements DNS

Chaque type d'enregistrement répond à un besoin différent.

A : nom vers IPv4
AAAA : nom vers IPv6
CNAME : alias vers un autre nom
MX : serveurs de réception du courrier
TXT : informations textuelles, notamment certains paramètres de sécurité

SPF, DKIM et DMARC sont des mécanismes utilisés pour la sécurité des courriels. Ils s'appuient notamment sur des enregistrements DNS de type TXT.

6. DNS et cybersécurité
Une mauvaise configuration ou une modification malveillante des réponses DNS peut rediriger l'utilisateur vers un faux service ou rendre un site inaccessible.
Exemple : le nom d'un site pointe vers une mauvaise adresse IP.
Parmi les risques : détournement DNS, hameçonnage, vol d'identifiants et interruption de services. Les protections de messagerie SPF, DKIM et DMARC seront approfondies dans le cours sur la messagerie.


7. Reverse DNS (PTR)
La résolution inverse sert à rechercher un nom à partir d'une adresse IP. Elle utilise un enregistrement PTR.
192.0.2.10
↓
10.2.0.192.in-addr.arpa
↓ (si un PTR existe)
athenyx.net
Pour une adresse IPv4, les quatre nombres sont inversés dans le nom de recherche. La réponse dépend de l'existence et du contenu de l'enregistrement PTR.

1. À quoi sert le DNS ?

Le DNS (Domain Name System) permet notamment de retrouver l'adresse IP associée à un nom. Cela évite de devoir mémoriser une adresse IP pour chaque service.

Exemple :
www.athenyx.net
↓
192.0.2.10

Un ordinateur demande au serveur DNS l'adresse associée à un nom. Le DNS fournit une réponse, puis l'ordinateur peut contacter le service recherché.

À retenir : le DNS permet de retrouver des informations associées à des noms, notamment des adresses IP. Il ne transporte pas les pages web.

Messagerie d'entreprise

1. Comment circule un courriel ?

Un courriel part d'un utilisateur, passe par un service de messagerie, puis arrive sur le service du destinataire. Le destinataire le consulte ensuite sur son PC ou smartphone.

CyberNet Rennes : Camille envoie un message de camille@cybernet.fr vers support@frtelix.net. Le serveur destinataire conserve le message pour son utilisateur.

2. SMTP : envoyer les courriels

SMTP sert à envoyer les messages. Dans la configuration classique d'un logiciel de messagerie, on indique un serveur SMTP pour l'envoi.

Compte      : camille@cybernet.fr
Serveur SMTP: smtp.cybernet.fr
Port        : 587 (submission)

Le port 25 est utilisé notamment pour les transferts entre serveurs. Le port 587 sert couramment à l'envoi authentifié depuis un logiciel.

3. POP3 : récupérer les courriels

Avec POP3, le logiciel récupère les messages sur le poste. Selon les réglages, les copies sur le serveur peuvent être conservées ou supprimées. POP3 n'assure pas la synchronisation complète entre plusieurs appareils.

Un salarié lit ses messages sur un PC. Son smartphone ne retrouve pas forcément les mêmes messages lus ou classés.

Ports usuels : 110 (POP3) ou 995 (POP3 sécurisé).

4. IMAP : consulter une boîte synchronisée

Avec IMAP, les courriels et dossiers restent principalement sur le serveur. Plusieurs appareils peuvent consulter et synchroniser la même boîte.

Camille supprime un message sur son PC : le message disparaît également de la boîte consultée depuis son smartphone, après synchronisation.

Ports usuels : 143 (IMAP) ou 993 (IMAP sécurisé).

5. Microsoft 365 et Google Workspace

Microsoft 365 (Exchange Online) et Google Workspace (Gmail professionnel) sont des solutions de messagerie et de travail collaboratif hébergées dans le cloud.

Elles peuvent réunir courriels, calendriers, contacts, partage et gestion des utilisateurs. Les employés utilisent un navigateur, leur smartphone ou un logiciel compatible.

Avec ces plateformes, il faut distinguer la synchronisation de la boîte mail et les fonctions collaboratives : calendrier partagé, contacts, réunions et ressources.

6. Boîtes individuelles et partagées

Chaque salarié dispose de sa boîte professionnelle personnelle, par exemple alex@cybernet.fr. Une boîte partagée, par exemple sav@cybernet.fr, peut être consultée par plusieurs techniciens autorisés.

Camille, Alex et Josh traitent les demandes arrivant à sav@cybernet.fr. Une boîte partagée permet de mieux coordonner le travail sans utiliser un compte commun avec un mot de passe partagé.
